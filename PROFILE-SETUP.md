# Publish your profile

Upload `README.md` and `assets/profile-hero.svg` to the public **Frankpesta/Frankpesta** repository, preserving the assets folder. Your previous README is saved locally as `README.previous.md`.

The hero is a self-contained SVG with no scripts or external fonts. Optional statistics, badges, and toolkit icons use external services.

Suggested pins: `49gig`, `ticketing`, `franklin_portfolio`, plus three projects you most want to discuss with collaborators.

Project facts come from the existing README and public GitHub repository metadata. The original portfolio URL is preserved.
